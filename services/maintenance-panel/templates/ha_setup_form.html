Настройка HA-кластера

Запускать ЭТУ форму отдельно на КАЖДОМ из двух серверов, с разными параметрами (на одном — роль «master», на другом — «backup», VIP одинаковый на обоих). На сервере с ролью master в процессе настройки снимается дамп базы данных и передаётся по SSH на второй сервер — это может занять несколько минут.
Перед запуском на каждом из двух серверов должен быть настроен SSH-доступ по ключу к другому серверу — либо вручную заранее (см. ниже), либо автоматически прямо в этой форме, если заполнить поля «Автоматическая настройка доступа к соседу».
Вариант вручную — это две отдельные команды, выполнять по очереди, не одной строкой: 
ssh-keygen -t rsa -b 4096 -N "" -f ~/.ssh/id_rsa
Дождаться завершения (если ключ уже был создан раньше — эту команду можно пропустить), затем отдельно: 
ssh-copy-id root@<IP второго сервера>
Выполнить на обоих серверах, указывая в каждом IP другого сервера.
Firewall FreePBX по умолчанию блокирует подключение с соседнего сервера, в том числе SSH — а это правило теряется при переустановке ОС/FreePBX (в отличие от кода панелей, который тянется из git). Настройка сама открывает себя навстречу соседу при запуске, но для самого первого SSH-подключения (шаг выше) нужна взаимность — если оба сервера только что переустановлены, выполните заранее на каждом: 
fwconsole firewall add trusted <IP второго сервера>/32
fwconsole firewall restart

Определено автоматически по интерфейсам этого сервера — выберите нужный, если их несколько.

Автоматическая настройка доступа к соседу (необязательно)

Если SSH-ключ к второму серверу ещё не настроен вручную — заполните поля ниже, и настройка сама разложит ключ и поправит firewall на соседе через обычного администратора (не root). Пароль нигде не сохраняется, используется только для этого запуска. Оставьте пустыми, если ключ уже настроен вручную.
