Дамп FreePBX из резервной копии

Дамп содержит конфигурацию FreePBX (номера, транки, маршруты) на момент снятия резервной копии — БЕЗ истории звонков и записей. Применять только на текущем master (том сервере, где сейчас VIP) — резервный узел получит изменения сам через обычную репликацию. Применение дампа напрямую на backup при активной репликации может её разорвать.

Файл только извлекается на диск сервера — команда для фактического применения выводится после извлечения, выполнить её нужно вручную.
