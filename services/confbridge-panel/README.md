# ConfBridge Panel

Веб-панель управления конференциями Asterisk 22 / FreePBX 17. Список активных конференций и участников в реальном времени, управление звуком, автоматическая запись, приглашение и обзвон, роли участников (модераторы/обычные), история подключений, управление учётными записями.

Распространяется под лицензией MIT (см. [LICENSE](LICENSE)) — используйте, дорабатывайте и распространяйте свободно.

## Требования

- Debian 12
- Asterisk 22 LTS + FreePBX 17
- Модуль `app_confbridge.so` загружен (`asterisk -rx "module show like confbridge"` → статус `Running`)
- **Python 3 — обязательное требование.** Без него `install.sh` сразу остановится с ошибкой; на Debian 12 обычно уже установлен, проверить: `python3 --version`
- Flask, flask-cors — `install.sh` проверяет их сам и при необходимости ставит автоматически (`pip3 install --break-system-packages flask flask-cors`); если автоустановка не удалась, скрипт остановится с точной командой, которую нужно выполнить вручную
- `mysql-client` — опционально, нужен только для функции «Выбрать из базы АТС» (чтение списка добавочных номеров прямо из базы FreePBX); без него панель работает, просто эта одна функция будет недоступна

## Установка

```bash
git clone <URL-этого-репозитория> asterisk-panel-src
cd asterisk-panel-src
sudo bash install.sh
```

Скрипт `install.sh` сначала задаёт несколько вопросов про настройки сервера — на каждый можно просто нажать **Enter**, чтобы принять значение по умолчанию (не обязательно ничего вводить, если Asterisk и панель на одном сервере):

- адрес сервера Asterisk (по умолчанию `127.0.0.1`);
- порт AMI (по умолчанию `5038`);
- порт, на котором будет работать сама панель (по умолчанию `5000`);
- папка с записями конференций (по умолчанию `/var/spool/asterisk/monitor`).

Дальше `install.sh` делает всё сам:

- проверяет ConfBridge и зависимости;
- копирует файлы в `/opt/asterisk-panel` и подставляет в них указанные выше настройки;
- генерирует случайный пароль AMI и прописывает его и в `/etc/asterisk/manager_custom.conf`, и в `api.py` (вручную синхронизировать ничего не нужно);
- создаёт и запускает systemd-сервис `asterisk-panel`;
- по желанию сразу заводит первую конференц-комнату (спросит номер и название — можно пропустить и настроить позже через интерфейс);
- выводит адрес панели и пароль администратора;
- удаляет временную папку, из которой запускался (там, где лежали `api.py`, `index.html`, `install.sh`) — файлы панели уже скопированы в `/opt/asterisk-panel`, эта папка больше не нужна. Если скрипт запущен прямо из системной директории (`/opt`, `/home`, `/root` и т.п. без отдельной подпапки) — автоудаление пропускается из соображений безопасности, тогда уберите папку вручную.

Скрипт безопасно перезапускать повторно — если пользователь AMI `[dashboard]` уже настроен, install.sh не станет его пересоздавать.

После установки панель доступна по адресу `http://<IP-сервера>:<указанный порт>/` (по умолчанию порт `5000`). Пароль администратора выводится один раз в конце установки и сохраняется в `/opt/asterisk-panel/admin_password.txt` — смените его после первого входа кнопкой **«Сменить пароль»** в шапке панели.

Конференции панель не придумывает сама — их нужно завести хотя бы одну (через `install.sh` при установке или в любой момент позже через вкладку **«Приглашение» → «⚙️ Конференц-комнаты»**).

## Обновление

```bash
sudo systemctl stop asterisk-panel
sudo cp /opt/asterisk-panel/api.py /opt/asterisk-panel/api.py.bak-$(date +%Y%m%d)
sudo cp /opt/asterisk-panel/index.html /opt/asterisk-panel/index.html.bak-$(date +%Y%m%d)
# скопировать новые api.py и index.html в /opt/asterisk-panel/
sudo chmod 777 /opt/asterisk-panel/api.py /opt/asterisk-panel/index.html
sudo systemctl start asterisk-panel
```

База данных при обновлении не пересоздаётся — старые данные (конференции, контакты, история, пользователи, модераторы) сохраняются, новые таблицы создаются автоматически при первом запуске новой версии.

## Удаление

```bash
sudo bash /opt/asterisk-panel/uninstall.sh
```

Останавливает сервис, удаляет systemd-юнит, убирает пользователя AMI (с резервной копией `manager_custom.conf`) и полностью удаляет `/opt/asterisk-panel`, включая базу данных.

## Основной функционал

- **Конференции** — список активных конференций с участниками, заглушение/включение звука, удаление участника
- **Записи** — автоматическая запись (старт с первого подключившегося, стоп с последним отключившимся), скачивание и удаление файлов
- **Приглашение** — одиночные и массовые звонки, управление списком конференц-комнат прямо из интерфейса, адресная книга, импорт номеров прямо из базы FreePBX, статус набора с повторным вызовом для неответивших, список модераторов (заходят в конференцию сразу со звуком)
- **История** — журнал подключений/отключений с фильтром по дате и участнику
- **Пользователи** — создание и удаление учётных записей панели прямо из интерфейса (вкладка видна только роли «Администратор»)

## Роли и права

Четыре встроенные роли — администратор, менеджер, оператор, наблюдатель — с разным набором прав (просмотр, управление звуком, приглашения, доступ к истории и записям). Управление пользователями панели — во вкладке «Пользователи», доступной только администраторам.

Вкладки в интерфейсе показываются только тем, у кого есть соответствующее право: «Пользователи» видна только администратору, «Записи» — только ролям с правом `recordings` (по умолчанию администратор и менеджер; у оператора и наблюдателя эта вкладка скрыта).

## Архитектура

Панель использует четыре независимых соединения с Asterisk Manager Interface (AMI) — для обычных запросов, приглашений, записи и отдельно для прослушивания событий, с явным отключением подписки на события (`Events: off`) там, где она не нужна. Такое разделение устраняет зависания интерфейса при долгих операциях (массовый обзвон, запись). Подробности — в приложенной инструкции.

## Безопасность

- Все запросы к базе данных параметризованы — SQL-инъекции исключены
- Пароли хранятся в виде хешей (SHA-256), не открытым текстом
- Сессионный ключ Flask генерируется случайно при первом запуске и хранится с ограниченными правами доступа
- Пароль AMI генерируется случайно при установке, не хранится в открытом виде в репозитории
- Защита от CSRF: cookie сессии выставлены с флагом `SameSite=Lax`, плюс отдельный CSRF-токен, который выдаётся при входе и проверяется на каждый запрос, меняющий состояние (POST/PUT/DELETE) — сторонний сайт не сможет воспользоваться чужой активной сессией в браузере пользователя
- Панель по умолчанию работает по HTTP без шифрования — это осознанное решение для внутренней сети за файрволом (подробности и рекомендации по HTTPS — в разделе ниже)

### Про HTTPS

Панель не включает HTTPS «из коробки» — она рассчитана на использование во внутренней сети предприятия, куда нет доступа снаружи, наравне с самим Asterisk/FreePBX. В таких условиях трафик между админом и панелью не покидает локальную сеть, и переносить на пользователя обязательную настройку сертификатов ради инструмента для внутреннего пользования показалось избыточным.

Если вы разворачиваете панель там, где к её порту есть доступ из недоверенной сети (например, панель проброшена наружу или сеть не полностью изолирована) — обязательно поставьте перед ней reverse-proxy (Nginx/Caddy) с TLS-сертификатом (Let's Encrypt подходит) и не открывайте этот порт напрямую наружу. Добавлять встроенную поддержку HTTPS прямо в Flask-приложение не планируется — эта задача по архитектуре лучше решается на уровне reverse-proxy, а не внутри самого приложения.
