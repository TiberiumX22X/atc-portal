# Alert Panel — панель массового оповещения для Asterisk/FreePBX

Веб-панель для запуска массового голосового оповещения (сирена/эвакуация/
объявление) на парк SIP-телефонов через Asterisk. Заменяет захардкоженные
кнопки на телефонах и IVR-номера отдельным веб-интерфейсом с ролями,
журналом, синхронизацией списка номеров из FreePBX и проверкой реальной
доступности перед звонком.

## Возможности

- Роли **администратор** / **оператор**
- Типы оповещений с прикреплённой аудиозаписью (WAV, PCM 16-bit/8kHz)
- Автоответ на телефоне через `Call-Info`/`Alert-Info: answer-after=0`
- CallerID берётся из названия оповещения
- Синхронизация списка номеров напрямую из БД FreePBX (таблица `users`,
  только записи с заполненным именем)
- Перед рассылкой панель проверяет через AMI (`pjsip show contacts`), кто
  реально сейчас зарегистрирован, и звонит только доступным номерам
- Дозвон идёт в фоновом потоке (не блокирует интерфейс), отдельная
  AMI-команда на каждый номер — не подвержено ограничению длины
  dialplan-переменной при больших списках
- Журнал всех запусков с деталями (сколько дозвонилось, кто пропущен,
  какие были отказы)

## Требования

- Asterisk 18+ с PJSIP, FreePBX 15+
- Debian/Ubuntu, Python 3.9+
- Доступ к MySQL/MariaDB БД FreePBX (`mysql -u root asterisk`, обычно без
  пароля через локальный сокет на самой станции)

## Установка

```bash
git clone <URL-репозитория> alert-panel
cd alert-panel
chmod +x install.sh
sudo ./install.sh
```

Появится меню:

```
1) Установить / обновить
2) Удалить
3) Отмена
```

Либо без меню, сразу:

```bash
sudo ./install.sh --install
sudo ./install.sh --uninstall
```

Установщик:
- поднимает venv и зависимости
- создаёт AMI-пользователя в `manager_custom.conf` (идемпотентно —
  повторный запуск синхронизирует пароль, не плодит дубли)
- добавляет dialplan-контекст `alert-panel-room` в
  `extensions_custom.conf`
- поднимает systemd-сервис на порту **8091**
- по желанию удаляет временную папку, из которой запускалась установка

Пароль администратора при первой установке — в логе:
```bash
journalctl -u alert-panel -n 50 --no-pager | grep -A1 'Создан пользователь'
```

## Архитектура дозвона

Каждый номер получает отдельную короткую AMI-команду `Originate`
(`Channel/<номер>` → контекст `alert-panel-room`), а не один общий вызов
со списком всех номеров сразу — у Asterisk есть внутренний лимит на
длину dialplan-переменной (~4096 байт), из-за которого длинный список
номеров через одну переменную обрезался посередине.

Перед рассылкой панель запрашивает у Asterisk текущий список реально
зарегистрированных контактов и звонит только им — это и снижает
нагрузку на PJSIP при больших списках с массой офлайн-номеров, и не
тратит время на заведомо недоступные телефоны.

## Известные ограничения

- Проигрывание записи (`Playback`) поддерживает WAV (линейный PCM,
  16 бит, 8/16 кГц), GSM, µ-law/A-law, sln нативно; MP3 требует модуль
  `format_mp3`, который не всегда собран в поставке Asterisk
- CSRF-защита — простой session-based токен, без внешних зависимостей
  (не Flask-WTF)
- Пул потоков PJSIP по умолчанию мал (4 потока) — при больших списках
  (сотни одновременных `Originate`) стоит увеличить через
  `pjsip_custom.conf`:
  ```ini
  [system]
  type=system
  threadpool_initial_size=20
  threadpool_auto_increment=10
  threadpool_max_size=100
  ```
  и перезапустить Asterisk целиком (`core restart now`) — пул
  создаётся один раз при старте, простой `module reload` его не
  пересоздаёт
