# Монитор АТС

Статусы всех добавочных (в сети/не в сети, IP:порт) и счётчик одновременных
разговоров — аналог экрана "Монитор АТС" Yeastar K2, вкладки "Номера" и
"Одновременные вызовы" (вкладки "Линии"/"Конференция" по решению не нужны).

## Установка

```bash
sudo ./install.sh --install
```

Скрипт сам:
- создаёт `/opt/monitor-panel`, виртуальное окружение, ставит зависимости
- заводит AMI-пользователя `monitorpanel` в `manager_custom.conf` со случайным
  паролем и правами только на чтение статусов/команды диагностики
- читает креды FreePBX-БД из `/etc/freepbx.conf` (только SELECT из таблицы
  `users` — имена добавочных, доступ на запись не используется)
- регистрирует systemd-сервис на порту **8093**

После установки откройте `http://<IP-сервера>:8093/` — при первом входе
создайте администратора (`/setup`). Единственная учётная запись, роли не
предусмотрены (администрирует один человек). Логин и пароль можно сменить
позже на странице «Сменить пароль» в верхнем меню.

## Важно: один воркер

Сервис ведёт единственный фоновый поток опроса AMI раз в 20 секунд. gunicorn
запускается с `--workers 1 --threads 8` — НЕ увеличивайте число воркеров,
иначе AMI будет опрашиваться параллельно несколько раз одним и тем же
процессом-дублем. Параллельных пользователей это не ограничивает — потоки
(`--threads 8`) обслуживают браузерные запросы независимо от фонового опроса.

## Как это работает

- Раз в 20 секунд панель посылает в Asterisk через AMI команды
  `pjsip show contacts` (кто сейчас зарегистрирован, с каким IP:портом) и
  `core show channels` (для счётчика одновременных разговоров), плюс читает
  имена добавочных из FreePBX
- Результат складывается в общий кеш в памяти процесса; каждый открытый в
  браузере просмотр страницы просто читает этот кеш — сама панель не создаёт
  дополнительной нагрузки на AMI при заходах пользователей
- Автообновление на странице — через AJAX-запрос каждые 20 секунд, без
  перезагрузки всей страницы (сохраняются фильтр поиска и текущая страница)

## Удаление

```bash
sudo ./install.sh --uninstall
```
Спросит, удалять ли AMI-пользователя и папку `/opt/monitor-panel`.
