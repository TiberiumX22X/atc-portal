# Монитор АТС — статус звонка по добавочному (11.09.2026)

Раньше "Монитор АТС" показывал только регистрацию (в сети/не в сети,
`pjsip show contacts`). Теперь добавлен третий столбец "Активность" —
разговаривает номер сейчас или у него идёт звонок (набор/дозвон).

## Как это устроено

`poller.py` каждый цикл опроса (3 сек, `POLL_INTERVAL_SECONDS`) заодно
выполняет `core show channels concise` — построчный машинно-читаемый
формат (`Channel!Context!Exten!Priority!State!...`). Номер добавочного
берём из ИМЕНИ канала (`PJSIP/7001-00000012` → `7001`), не из поля Exten
— оно показывает набираемый номер, а не владельца телефона.

Состояния канала Asterisk сведены в две группы:
- `Up` → "Разговор" (`in_call`)
- `Ring`/`Ringing`/`Dialing`/`Pre-ring` → "Звонок" (`ringing`, пульсирующий бейдж)

Если у одного номера одновременно несколько каналов (перевод,
конференция) — показывается более "активное" состояние (Разговор
перекрывает Звонок).

Транковые каналы (`PJSIP/ToSomeTrunk-...`) в разбор
не попадают — регулярка на имя канала матчит только `PJSIP/<цифры>-`,
что соответствует формату добавочных (`EXTENSION_REGEX` в config.py),
не именам трансков.
